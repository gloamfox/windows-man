终端中中文文件名显示为 '$'\344\270\211\347\272\247' 这类八进制转义序列，根本原因是系统的 Locale（区域语言环境）未正确配置为 UTF-8，导致 ls 等命令无法识别中文字符，转而采用兼容性转义格式输出。

## 快速修复：临时生效

在终端直接执行以下命令，将当前会话的编码切换为 UTF-8（执行后立即生效，关闭终端即失效）：

```bash
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8
```


## 永久修复：写入配置文件

为了避免每次重启终端后重新设置，可以将环境变量追加到用户配置文件中：


如果你使用的是 Bash（默认通常是 ~/.bashrc）：

```bash
echo 'export LANG=zh_CN.UTF-8' >> ~/.bashrc
echo 'export LC_ALL=zh_CN.UTF-8' >> ~/.bashrc
source ~/.bashrc
```

如果你使用的是 Zsh（通常是 ~/.zshrc）：

```bash
echo 'export LANG=zh_CN.UTF-8' >> ~/.zshrc
echo 'export LC_ALL=zh_CN.UTF-8' >> ~/.zshrc
source ~/.zshrc
```
