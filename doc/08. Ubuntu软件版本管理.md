## 前言
update-alternatives 是 Debian/Ubuntu 系统中用于管理同一功能软件多个版本的官方工具。它的核心作用是，当系统里同时安装了多个提供相同功能的程序（比如多个版本的 Python、GCC 或 Java）时，由它来统一决定当你输入通用命令（如 python 或 gcc）时，实际调用的是哪一个版本。

## 🛠️ 常用命令速查

```bash
sudo update-alternatives --config <名称>    # 交互式切换默认版本，最常用。
update-alternatives --list <名称>           # 列出对应软件已安装的版本
sudo update-alternatives --set <名称> <实际路径>  # 在非交互情况下，直接将默认版本设置为指定路径。

```

## 注意事项

- 不要手动 ln -sf 覆盖系统命令：直接强制修改 /usr/bin/python3 或 /usr/bin/java 等链接是高风险行为。系统工具可能依赖特定版本，手动覆盖可能导致包管理器（如 apt）或桌面环境异常。

- 分清使用场景：update-alternatives 适合系统级的共享命令管理（如 gcc, java）。如果是用户级的开发环境（如为单个项目切换 Python 版本），使用 pyenv、nvm 或虚拟环境（venv/conda）是更合适、更隔离的选择。

update-alternatives 是系统管理员在多版本共存环境中维持秩序的基础工具，它通过标准化的链接管理，避免了“链接地狱”，让版本切换变得可追溯、可回退。
