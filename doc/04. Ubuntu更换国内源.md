通过之前的步骤我们已经在windows上搭建了一个ubuntu的系统，开发依赖的环境都可以在ubuntu中安装，但是由于众所周知的原因，国内用户使用默认的源安装软件速度很感人，更换成国内源就成了必要的操作。

执行以下命令查看ubuntu版本
```bash
lsb_release -a
```
## 22.04 及更早版本

以下操作都必须在管理员模式下（使用su命令进入）进行，否则会执行失败

**备份官方源**

```bash
mv /etc/apt/sources.list /etc/apt/sources.list.bk
```


**下载第三方源文件更换**

具体使用哪一个，可以自行测试按照效果选用
```bash
#163源
wget 'https://gitee.com/zaozuotime/ubuntu-update-source-file/raw/master/163.sources.list' -O /etc/apt/sources.list

#阿里源
wget 'https://gitee.com/zaozuotime/ubuntu-update-source-file/raw/master/aliyun.sources.list' -O /etc/apt/sources.list

#清华源
wget 'https://gitee.com/zaozuotime/ubuntu-update-source-file/raw/master/tsinghua.sources.list' -O /etc/apt/sources.list

#中科大源
wget 'https://gitee.com/zaozuotime/ubuntu-update-source-file/raw/master/ustc.sources.list' -O /etc/apt/sources.list
```

**更新资源**

```bash
apt-get update
```

## 24.04之后版本

### 一键 sed 替换（推荐，最快）

这是最省事的方式，直接修改配置文件并立即更新。以阿里云源为例，在终端执行：

```bash
sudo cp /etc/apt/sources.list.d/ubuntu.sources /etc/apt/sources.list.d/ubuntu.sources.bak

sudo sed -i 's|http://archive.ubuntu.com/ubuntu|https://mirrors.aliyun.com/ubuntu|g; s|http://security.ubuntu.com/ubuntu|https://mirrors.aliyun.com/ubuntu|g' /etc/apt/sources.list.d/ubuntu.sources
```

如果你更偏好清华源，把上面命令中的 `mirrors.aliyun.com` 全部替换为 `mirrors.tuna.tsinghua.edu.cn` 即可。
执行完替换后，运行更新：

```bash
sudo apt update
```
