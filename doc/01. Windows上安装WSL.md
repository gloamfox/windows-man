
## 1. 检查windows版本
- Windows 11：所有版本均支持。
- Windows 10：需要 版本 2004（Build 19041）或更高。如果版本过低，请先通过“设置 → 更新和安全 → Windows 更新”升级。

## 2. 安装WSL

管理员权限运行Windows PowerShell，然后输入并执行：

```powershell
wsl --install
```

这条命令会自动完成四件事：

1. 启用 适用于 Linux 的 Windows 子系统 和 虚拟机平台 两个必需功能。
2. 下载并安装最新的 Linux 内核。
3. 将 WSL 2 设置为默认版本。
4. 下载并安装默认的 Ubuntu 发行版。

执行命令后，系统可能会提示需要重启。这是正常流程，重启电脑即可。如果重启后 Ubuntu 没有自动完成安装
再次打开管理员终端，执行 `wsl --install -d Ubuntu` 继续即可。

## 3. Ubuntu 的初始设置

重启后，Ubuntu 通常会自行启动，并进入一个命令行界面，提示你创建 Linux 用户。

1. 输入一个新的用户名（建议不要与 Windows 用户名重复），按回车。

2. 设置密码。注意：输入密码时屏幕上不会有任何显示（包括星号），这是 Linux 的安全机制，正常盲打输入后按回车即可。

这个账户将成为你 WSL 中的默认用户和 Linux 管理员，之后所有需要提权的操作，都可以通过 sudo 命令来完成。

设置完成后，你就进入了 Ubuntu 的命令行。可以运行一个简单命令验证一下：

```bash
lsb_release -a
```

如果正常输出 Ubuntu 的版本信息，说明 WSL 的核心安装已经成功。


## 💡 为开发环境做的额外准备

WSL 安装完成，只是搭建开发环境的第一步。为了让后续的开发体验更顺畅，有个习惯值得从开始就建立起来。

**将项目文件存放在 WSL 文件系统内**

这是对开发体验影响最大的一个选择。WSL在访问 Windows 文件系统（/mnt/c/...）时，跨系统文件操作的性能损耗很大。跨文件系统访问的性能差距可能超过 300%。因此，你的代码仓库、项目文件应该直接放在 Linux 的家目录下，例如 ~/projects/。当你在 Windows 资源管理器中需要访问这些文件时，可以在地址栏输入 \\wsl$\Ubuntu\home\<你的用户名>\ 直接打开。
