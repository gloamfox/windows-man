## Clash Verge

代理工具中的常青树，功能无需多言。

[官方仓库](https://github.com/clash-verge-rev/clash-verge-rev)

## WinMerge

用于对比文件夹和文件的差异，个人认为最好用的是文件夹内容对比功能。

[官方地址](https://winmerge.org/)

## 7zip

Windows 11 自带的压缩/解压功能其实已经够用，但功能相对单一，7-Zip 是一个很好的补充。

[官方地址](https://sparanoid.com/lab/7z/)

## pdf24

免费 PDF 编辑工具，大多数 PDF 编辑场景都能覆盖；提供网页版，也可下载到本地安装使用。

[官方地址](https://tools.pdf24.org/zh/edit-pdf)

## Obsidian

笔记软件，功能无需多言。用得好是神器，用不好很快就会被劝退。

[官方地址](https://obsidian.md/)

## Everything

文件名搜索速度极快，资源占用低。

[官方地址地址](https://www.voidtools.com/zh-cn/)

## 滴答清单

用于记录待办事项。同类 to-do 软件很多，但滴答清单最符合我的审美和操作习惯。

[官方地址](https://dida365.com/webapp/)

## Postman

开发人员必备接口测试工具。

[官方地址](www.postman.com)

## SwitchHosts

方便管理本地电脑的 hosts 文件。

[官方地址](https://switchhosts.app/zh)

## MobaXterm

个人比较喜欢的一款终端工具。

[官方地址](https://mobaxterm.mobatek.net/)

## es-client

Windows 下个人使用较多的一款 Elasticsearch 客户端，在没有 Kibana 的情况下可用于查询 ES 数据、执行语句。

桌面版仅有 14 天试用期，Chrome/Edge 插件可免费使用；如不想在浏览器中使用，可在 GitHub 下载 2.6.1 之前的版本。

[官方地址](https://es-client.esion.xyz/)

仓库：[Gitee](https://gitee.com/qiaoshengda/es-client) | [GitHub](https://github.com/q2316367743/es-client)  |  [GitLink](https://www.gitlink.org.cn/m17762618644/es-client)



## Another Redis Desktop Manager

Redis 客户端工具，能直接展示二进制、protobuf、gzip 等非纯文本存储内容，排查数据时不用额外转换，比较方便。

[下载地址](https://github.com/qishibo/AnotherRedisDesktopManager/releases)
