在同一台机器上切换多个 Node.js 版本，NVM（Node Version Manager）是个灵活的选择。

## 🚀 第一步：安装或更新 NVM

NVM 的安装脚本会从 GitHub 拉取最新版本。根据你系统的情况，选择对应命令：
```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash
```

这里使用了 NVM 较新的稳定版本 v0.40.8。你也可以访问 [NVM GitHub Releases](https://github.com/nvm-sh/nvm/releases) 页面查找绝对最新的版本号进行替换。

如果你已安装过 NVM，想更新到最新版，最简单的方式是重新执行安装脚本，它会自动更新。

## 🔄 第二步：加载 NVM 环境

安装脚本通常会自动尝试将 NVM 加载到你的 shell 配置中。为了确保当前终端立即可用，需要手动加载一下配置文件：

```bash
source ~/.bashrc
```

如果你使用的是 zsh，请将命令替换为 `source ~/.zshrc`。


验证 NVM 是否安装成功：

```bash
nvm --version
```

如果显示了版本号（如 0.40.8），就说明 NVM 已就绪。

## 📦 第三步：安装最新版本的 Node.js

NVM 提供了两个快捷命令来安装“最新版本”，它们指向不同的通道：

```bash
# 最新版，体验最新特性，可能不够稳定
nvm install node

# 最新LTS版，生产环境推荐，长期支持更稳定
nvm install --lts
```

## ⚙️ 第四步：验证与设为默认

无论安装了哪个版本，都可以通过以下命令验证当前使用的 Node.js 和 npm 版本：

```bash
node -v
npm -v
```
