

apt 是 Ubuntu/Debian 下常用的包管理命令。大多数“安装/卸载/更新”操作需要 sudo，查询类命令一般不需要。

## 1. 更新软件包索引与升级

```bash
sudo apt update                  # 更新软件源索引（不升级软件）
sudo apt upgrade                 # 升级已安装软件（一般不会删除包）
sudo apt full-upgrade            # 完整升级，必要时可安装/删除包解决依赖
sudo apt update && sudo apt upgrade -y   # 常用组合
```

## 2. 安装软件

```bash
sudo apt install 包名                 # 安装软件
sudo apt install 包1 包2              # 一次安装多个
sudo apt install ./xxx.deb            # 安装本地 deb 包，并尝试解决依赖
sudo apt install --reinstall 包名     # 重装
sudo apt install --no-install-recommends 包名  # 不安装推荐依赖
```


## 3. 卸载软件

```bash
sudo apt remove 包名              # 卸载，保留配置文件
sudo apt purge 包名               # 卸载并删除配置文件
sudo apt autoremove               # 删除不再需要的自动依赖
sudo apt autoremove --purge       # 删除依赖并清理其配置
```

## 4. 查询与搜索

```bash
apt search 关键字                 # 搜索软件包
apt search --names-only 关键字    # 根据软件名搜索
apt show 包名                     # 查看包详细信息
apt list --installed              # 列出已安装包
apt list --upgradable             # 列出可升级包
apt list -a 包名                  # 查看包的所有可用版本
apt list --installed | grep 关键字 # 在已安装包中过滤
apt changelog 包名                # 查看更新日志
```

配合 apt-cache 查询：

```bash
apt-cache policy 包名             # 查看版本和软件源优先级
apt-cache depends 包名            # 查看依赖
apt-cache rdepends 包名           # 查看被哪些包依赖
apt-cache search 关键字           # 搜索
apt-cache show 包名               # 查看包信息
```

## 5. 清理缓存

```bash
sudo apt autoclean      # 清理过期的包缓存
sudo apt clean          # 清理所有下载的 deb 缓存
sudo apt autoremove     # 清理无用依赖
```

## 6.  与 apt-get
日常交互推荐 apt，输出更友好。
脚本中更推荐 apt-get / apt-cache，因为 apt 的 CLI 输出格式不保证稳定。

```bash
sudo apt-get update
sudo apt-get install 包名
apt-cache search 关键字
```

## 最常用速查

```bash
sudo apt update
sudo apt upgrade
sudo apt install 包名
sudo apt remove 包名
sudo apt purge 包名
sudo apt autoremove
apt search 关键字
apt show 包名
apt list --installed
apt list --upgradable
sudo apt --fix-broken install
```
