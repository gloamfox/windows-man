## 项目介绍
这个项目的目的是为了手把手从0到1在windows下搭建一个开发环境，网上很多工具都是东一榔头西一棒槌的，没有一个统一个教程，这次借着重装系统的机会，将这些经验记录下来，一是为了给自己一个备忘方便以后查找，二是为了希望能帮助一些需要的同学，同时后面我使用开发过程中发现的一些好的软件、经验、技巧也会陆续更新到这里。


## 教程说明
本教程将教你从 0 到 1 配置一台得心应手的 Windows，涵盖终端环境、开发环境和效率工具等。

在 Windows 下开发，一个很痛苦的问题是：终端命令与实际生产环境很不一致，导致日常开发和生产运维相互割裂。幸运的是，Windows 支持的 WSL 已经能很好地支撑 linux 下的开发，后续开发相关的教程都基于 WSL 进行配置。

另外说句笑话：凭借 WSL，Windows 已经成为最好的 Linux 发行版🤣。
